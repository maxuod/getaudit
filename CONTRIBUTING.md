# Contributing

The project source is licensed under MIT. Follow these notes when contributing to this early-access source project.

Use synthetic fixtures, reserved example domains, and an isolated local database. Keep captured customer data and personal account configuration outside the repository.

Author interface copy in English first, then adapt the matching complete messages naturally into Simplified Chinese. Preserve message keys and parameters, the user's saved language, and original evidence text. Keep task status factual; helper copy must never invent progress or verification.

For code changes, run the type checks, relevant tests, locale checks, and production Console build described in the README. Describe what changed, why, what was tested, and any remaining limitation. Do not run paid providers merely to validate a UI change.

Keep required dependency notices intact. No release automation, deployment, external message, or account change is implied by a contribution.
